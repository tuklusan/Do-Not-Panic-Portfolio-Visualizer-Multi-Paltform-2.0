runtime identifiers. Each bundle includes `YFinanceServer/`,

## Running a bundle

1. Download the archive matching the machine architecture.
2. Verify its SHA-256 checksum.
3. Extract the archive without renaming `YFinanceServer/`.
4. On Linux or macOS, preserve the executable bit on
   `DoNotPanicPortfolioVisualizer.App` and launch it from the extracted
   directory. On Windows, launch `DoNotPanicPortfolioVisualizer.App.exe`.
